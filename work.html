Clinical ML

ICU Mortality Prediction System

An LSTM model that estimates in-hospital mortality risk from ICU time series, with explanations clinicians can check.

AUC-ROC
0.978
Avg precision
0.892
p95 latency
<800 ms
Challenge
ICU data is irregular and sparse, and it is easy to leak future information or the same patient into both training and test sets. Clinicians also need calibrated, explainable risk before they will use it.
Approach
Raw MIMIC-III/IV data through ETL with temporal alignment, normalisation and notes integration. 6–12 hour time bins, strict patient-level splits and leakage controls. An LSTM for prediction, XGBoost with SHAP for clinician-facing explanations, and a containerised inference API on Azure with CI/CD, drift monitoring and retraining triggers.
Outcome
AUC-ROC 0.978 and average precision 0.892 on a held-out cohort. SHAP explanations were validated by ICU clinicians and calibration was verified across risk deciles.

DataBuilt under PhysioNet and IRB protocols. A synthetic data generator that mimics the MIMIC schema lets the pipeline run without credentialed data access.

LLM · RAG · Clinical

Clinical Notes RAG System

Question answering over discharge summaries that keeps data on local infrastructure and measures its own accuracy.

Notes indexed
10K+
Inference
Local LLaMA, no external API
Evaluated on
Precision@k, faithfulness, hallucination rate
Challenge
Clinical notes are long, full of abbreviations and too sensitive to send to an external API. Answers have to stay faithful to the source text.
Approach
Hybrid retrieval that combines Bio_ClinicalBERT dense embeddings in FAISS with keyword search. DSPy-optimised prompt chains feed a locally hosted LLaMA model, served through FastAPI. DSPy was also used to generate augmented notes that widen coverage of rare cases.
Outcome
More than 10,000 clinical notes indexed. An evaluation harness tracks precision@k, answer faithfulness and hallucination rate on every iteration.

DataDeveloped and evaluated on public datasets (PubMedQA, MedQA) and synthetic notes.

FinTech · LLM

Smart Portfolio Insider

Natural-language analytics over portfolio data for wealth managers, running in production.

Status
Running in production
Platform
Bloxx wealth platform
Interface
Streaming answers in natural language
Challenge
Analysts wanted to ask questions of portfolio data in plain language, and the answers had to stay correct on numbers and time series.
Approach
Retrieval-augmented generation over financial dataframes with LangChain and DSPy, schema-aware prompt templates, output guardrails, streaming responses and reproducible evaluation. Packaged as Docker microservices with GitLab and Jenkins CI and FitNesse tests.
Outcome
Deployed to production and integrated into the Bloxx wealth platform with a streaming interface.

Process mining

Ticket System Process Mining

Descriptive, predictive and prescriptive analysis of IT service-desk event logs.

Analysis
Descriptive, predictive, prescriptive
Checks
Conformance and bottlenecks
Delivered
KPI impact report for stakeholders
Challenge
Service-desk processes rarely run the way they were designed. The goal was to find where tickets wait and why.
Approach
Event logs analysed in Celonis EMS, RapidMiner and ProM 6.11: process discovery, conformance checking and bottleneck analysis, followed by predictive and prescriptive steps.
Outcome
Bottlenecks identified and their KPI impact reported to stakeholders.

Research

GPU-Accelerated Branch and Bound

Combinatorial optimisation for vertex elimination in graphs, with the search parallelised on NVIDIA GPUs.

Problem
Vertex elimination in graphs
Method
Exact branch and bound
Hardware
NVIDIA GPUs with CUDA
Question
Vertex elimination problems on graphs are combinatorial: the number of possible elimination orders explodes as graphs grow.
Approach
An exact branch-and-bound search, with the work parallelised across NVIDIA GPUs using CUDA.
Takeaway
Hands-on experience with GPU programming and performance work that carries over to fast model inference.

  • NVIDIA GPUs
  • Branch and bound
  • Graph algorithms
