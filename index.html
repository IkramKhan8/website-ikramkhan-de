Process

How a project runs

The four stages I follow on every project, from the first question to a monitored service.

  1. 01

    Frame

    Start with the decision the model supports, the metric that matters and the data available. Success criteria are set before any code is written.

  2. 02

    Build

    A baseline first, then iteration. Proper splits, leakage checks and an evaluation report written for the people who decide.

  3. 03

    Explain

    SHAP, calibration and error analysis, reviewed with the people who will use the model every day.

  4. 04

    Ship & monitor

    A containerised service with CI/CD, drift monitoring and retraining triggers, plus documentation the team can own.
