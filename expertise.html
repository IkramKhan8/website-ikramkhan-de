What I do

Six areas, one standard

Each area is backed by work I have shipped. The proof line under each one shows where.

Predictive modelling

Risk scores, forecasts and classifiers built on time series and tabular data, evaluated the way they will be used.

What it covers

  • Problem framing and a success metric everyone agrees on
  • Baseline and tuned model with a full evaluation report
  • Calibration and error analysis by segment
  • Inference code ready for deployment

Tools

  • PyTorch
  • LSTM
  • XGBoost
  • scikit-learn
  • TensorFlow

ProofICU mortality model: AUC 0.978, average precision 0.892.ICU mortality case study

LLM & RAG systems

Assistants and analytics that answer from private documents and data, with retrieval you can measure.

What it covers

  • Hybrid retrieval over documents (dense and keyword)
  • Prompt programs optimised with DSPy
  • Local or hosted LLMs, depending on the data rules
  • Evaluation harness: precision@k, faithfulness, hallucination rate

Tools

  • DSPy
  • LangChain
  • FAISS
  • LLaMA
  • Hugging Face
  • FastAPI

ProofClinical Notes RAG over 10K+ notes, and the Smart Portfolio Insider in production.Clinical notes RAG case study

Explainable AI & dashboards

Making a model’s reasoning visible to the people who act on it, from global drivers down to a single case.

What it covers

  • SHAP analysis of global and per-case drivers
  • Dashboards built for domain experts
  • Model documentation in model-card format
  • Review sessions with the people using the model

Tools

  • SHAP
  • XGBoost
  • Power BI
  • Python

ProofClinician-facing SHAP dashboards for ICU mortality flags at Uniklinik RWTH Aachen.SHAP dashboards in the ICU case study

MLOps & deployment

Turning a working notebook into a service that is tested, versioned, monitored and easy to retrain.

What it covers

  • Dockerised model services with FastAPI
  • CI/CD with GitHub Actions, GitLab CI or Jenkins
  • Drift monitoring and retraining triggers
  • Experiment tracking and model versioning with MLflow

Tools

  • Docker
  • Kubernetes
  • Azure
  • Terraform
  • MLflow
  • Evidently AI
  • Prometheus
