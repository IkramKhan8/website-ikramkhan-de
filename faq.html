About me

My background, current role and how I work.

Problems where a model has to be accurate, explainable and running in production: risk and outcome prediction, LLM assistants over private documents, explainability for existing models, MLOps and process mining. Most of my experience is in healthcare, finance and operations.

Since September 2026 I work full-time as a Junior Data Scientist. The projects on this site come from my research and earlier roles, and my public code is on GitHub and Hugging Face.

I start with the decision the model should support, the metric that matters and the data available. Then come a baseline, an honest evaluation, explanations for the people who use the model, and a monitored deployment. The Expertise page covers each step.

In Aachen, Germany. Conversations and collaborations work just as well remotely.

English at C1, professional level. My German is at A2 and I’m working toward B1.

Technical

Deployment, evaluation and what happens after launch.

As Docker containers with FastAPI endpoints, with CI/CD in GitHub Actions, GitLab CI or Jenkins. I have deployed on Azure and worked with Kubernetes and Terraform-managed environments.

Yes. I have built RAG pipelines that run local LLaMA models, so documents and prompts stay on your own infrastructure. Retrieval quality and answer faithfulness are measured, so it is clear how well the system works before anyone relies on it.

Through evaluation that matches how the model will be used: patient- or customer-level splits, leakage checks, calibration, and metrics such as AUC, PR-AUC or precision@k. A good evaluation report also shows where the model is weak.

Models drift as data changes. I set up monitoring for prediction drift and feature distributions, with alerts and retraining triggers, and write documentation so the team running the model knows what to do.

My public projects are on GitHub (opens in a new tab) and my models on Hugging Face (opens in a new tab). Work I did for employers stays with them.

Data & privacy

Sensitive data and what can be shared.

Yes. At Uniklinik RWTH Aachen I worked with ICU patient data under PhysioNet and IRB protocols, and I hold CITI Program certifications in human research. Local models and synthetic data generators are part of how I design systems that handle sensitive data.

No. The ICU work used credentialed MIMIC data under PhysioNet rules, so it can’t be shared. The pipeline includes a synthetic data generator that mimics the MIMIC schema, so the code runs without credentialed access.
